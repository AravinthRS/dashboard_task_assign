# Taskline Ticket Dashboard

A responsive, standalone dashboard for managing a support team's ticket queue.

## Open the dashboard

Open [index.html](index.html) in a modern browser. No installation or build step is required.

## Features

- Ticket overview metrics and priority breakdown
- Search tickets and filter by status or priority
- Quick views for open, assigned, and resolved tickets
- Create tickets and inspect their details
- New tickets are saved in this browser using local storage
